## How I work

Every project here is built with an **engineering pipeline** that combines senior-level web development with AI-assisted iteration: coding agents implement features under strict protocols for architecture, code review, testing, and integration that I define and enforce.

What this means in practice:

- **Speed with quality gates:** parallel agent waves deliver in days what traditionally takes weeks, because every change passes automated CI, unit + E2E tests, and human review before merge.
- **Protocol-driven:** one issue → one branch → one PR. Verifiable acceptance criteria. Zero speculation.
- **Sustainable by design:** shared design systems, reusable libraries, and documented resource analysis keep long-term maintenance cost low — the same methodology I now offer as consulting through my [technical advisory sessions](https://portfolio-iberi22.vercel.app/agenda).
