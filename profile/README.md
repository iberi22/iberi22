## 🔧 Cómo mantener este formato

1. **Nueva app** → añade una fila en su categoría con los 4 enlaces (`repo/issues` = backlog, `repo/tree/<rama>/docs` = docs, repo = código, URL viva = demo).
2. **Demo lista** → mueve la app a "Apps con demo en vivo" y pega la URL.
3. **Lanzamiento público** → cambia 🔒 por 🔓 y el `issues`/`docs` dejarán de dar 404 a visitantes.
4. **Repo local sin GitHub** (ej. MiMatera) → columna Repo = `local` hasta publicarlo.
5. Mantén las URLs verificadas (un `curl -I` antes de subir cambios).
