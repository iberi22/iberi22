## 🚀 FLAGSHIP PROJECTS

### 🧠 Xavier (Rust) — The Cognitive Core
Agentic memory engine with **BM25 + Vector hybrid search**, **Belief Graph**, **MCP server**, **session virtualization**, and **100% local-first** operation. +90% token savings via progressive memory disclosure. Post-quantum identity, governance DAO.

`🔒 PRIVATE — Available after Node Network Launch`

### 🌐 Edge-Mesh (TypeScript) — P2P Backbone
Production-ready P2P mesh networking with **CRDT sync** (Yjs), **ML-DSA-65 post-quantum identity**, peer-to-peer transport. Every SWAL app connects through this layer.

`🔒 PRIVATE — Available after Node Network Launch`

### ⚖️ VeedurIA (Rust + Svelte) — Civic Oversight
Public procurement monitoring system using AI + open data. Monitors SECOP II contracts, citizen risk analysis with BERT. Multi-cloud Rust backend.

`🔒 PRIVATE — Open source post-audit`

### 📋 Shelf (TypeScript) — POS Offline-First
Production inventory and POS with **edge-mesh integration**, **offline-first** PWA. v1.2.1 active in field.

`🔒 PRIVATE`

### 🏥 OrionHealth (Flutter/Dart) — Sovereign Health
Privacy-first health assistant with **SSI (AnonCreds, DID, W3C VCs)**, clinical AI, offline medical standards (ICD-10, LOINC, RxNorm, SNOMED CT), and offline health wallet.

`🟢 PUBLIC — github.com/iberi22/OrionHealth`

### 🌍 WorldExams — Global Assessment Platform
Multi-country exam platform with +2000 curated questions for 16+ countries. Astro + Svelte + Supabase + PWA.

`🔒 PRIVATE`

### 🍳 GOS — Gastronomic Open Standard
Open standard for structured culinary documentation. Recipes by country, ingredients, nutritional data. P2P review data gos-p2p-data.

`🟢 PUBLIC — github.com/iberi22/gastronomic-open-standard-GOS`
