## 🌎 SouthWest AI Labs (SWAL) — the core idea

> **AI should live on YOUR device, not in someone else's data center.**

SWAL is my open-source lab. The core idea is simple: today your data and your AI depend on someone else's cloud — uploaded, sold, lost. We build the alternative:

- 🏠 **Local-first** — AI runs on your phone or computer and works even offline.
- 🔐 **Privacy-first** — your data never leaves your control; no exfiltration possible.
- 🕊️ **Sovereign** — everything is open source (AGPL-3.0) and portable: if the lab disappeared, your code and your data would still be yours.

To achieve this, the lab maintains **4 shared layers** used by every app:

| Layer | Project | What it solves |
|---|---|---|
| 🧠 Agentic memory | [Xavier](https://github.com/iberi22/xavier) | Agents with persistent memory that never forget context |
| 🌐 P2P network | [edge-mesh](https://github.com/iberi22/edge-mesh) | Sync your devices without going through the cloud |
| 🤖 Agent runtime | [swal-agent-runner](https://github.com/iberi22/swal-agent-runner) + [gestalt](https://github.com/iberi22/gestalt) | Run and orchestrate autonomous agents locally |
| 🎨 Design system | [@swal/ui](https://github.com/iberi22/swal-ui) | One visual identity for the whole ecosystem |

On top of those layers we build **apps with real-world impact**: accessible education, private health, local commerce, industrial maintenance and civic oversight.

## 🔧 How to maintain this format

1. **New app** → add a row in its category with review + 4 links (`repo/issues` = backlog, `repo/tree/<branch>/docs` = docs, repo = code, live URL = demo).
2. **Demo ready** → move the app to "Apps with live demo" and paste the URL.
3. **Public launch** → change 🔒 to 🔓 and `issues`/`docs` will stop 404ing for visitors.
4. **Local repo without GitHub** (e.g. MiMatera) → Repo column = `local` until published.
5. Keep URLs verified (a `curl -I` before pushing changes).
